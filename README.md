# iScholar: Intelligent Scholarship Prequalification System

**iScholar** is an intelligent scholarship prequalification and application management system.  
It helps schools, local governments, and organizations streamline scholarship applications using **fuzzy logic**, **prescriptive analytics**, and **automated eligibility checks**.

## ✨ Features

- 🎓 **Automated Prequalification**  
  Uses academic, financial, and family background data to compute scholarship eligibility.
  
- 📄 **Application Management**  
  Multi-step applicant forms, document uploads, and status tracking.

- 🔍 **Admin Dashboard**  
  View applications, generate reports, approve requests, and manage users.

- 🔒 **Secure Authentication**  
  Role-based access for admins and students (JWT-based API with refresh tokens).

- 🧠 **Fuzzy Logic Engine**  
  Customizable scholarship decision logic for fair and transparent screening.

## 🛠️ Technologies Used

- **Backend**: Python Flask + MySQL (raw SQL)  
- **Frontend**: React + Bootstrap 5  
- **Authentication**: JWT (Access & Refresh Tokens)  
- **Visualization**: ApexCharts, Recharts (Admin dashboard)
